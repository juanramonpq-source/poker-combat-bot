Modo horizontal recomendado

Gira el móvil para jugar

Este tutorial está pensado para jugar en horizontal, con más campo de visión y controles táctiles cómodos. Si tienes la rotación bloqueada, desbloquéala o gira el teléfono físicamente.

Algunos navegadores solo permiten bloquear orientación desde pantalla completa.

PoCoBOT // Mercado de Relés Muertos

Tutorial de movimiento en el mercado de Vera Hex. Desliza el PoCoBOT con WASD, ratón o táctil, y acércate a Vera o a Viajero para activar sus puntos de interacción. Pulsa E para seleccionar, hablar, combatir o salir.
