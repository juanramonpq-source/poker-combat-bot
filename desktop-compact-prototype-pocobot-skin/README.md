# Prototipo Desktop Skin PoCoBOT

Esta variante conserva la estructura compacta del prototipo desktop, pero rehace el aspecto visual para acercarlo al look clasico del juego actual.

## Abrirlo

- Directamente: `desktop-compact-prototype-pocobot-skin/index.html`
- Si tienes el servidor actual levantado: `http://localhost:3000/desktop-compact-prototype-pocobot-skin/`

## Objetivo

- Mantener la distribucion compacta para PC
- Evitar scroll vertical
- Conservar el ADN visual de PoCoBOT actual
- Probar una posible variante desktop sin tocar la interfaz real
