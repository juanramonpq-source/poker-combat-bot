# Prototipo Desktop Compacto

Este prototipo vive aparte del juego real y no modifica ninguna pantalla existente.

## Abrirlo

- Directamente: `desktop-compact-prototype/index.html`
- Con el servidor actual del proyecto: `http://localhost:3000/desktop-compact-prototype/`

## Objetivo

- Probar una vista compacta solo para PC
- Mantener todos los botones importantes visibles
- Evitar scroll vertical
- Separar claramente modulos, duelo central, acciones y mano
